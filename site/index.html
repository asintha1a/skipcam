INSTALL / BETA

Try SkipCam beta

SkipCam v1.0.0-beta.2 is an evaluation release. Automated tests and builds pass; full interactive browser QA is pending.

Chrome, Edge and Brave

Download Chromium beta ZIP ↓
  1. Extract the Chromium ZIP.
  2. Open your browser’s Extensions page and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder.

Firefox 140+

Download Firefox beta ZIP ↓
  1. Extract the Firefox ZIP.
  2. Open about:debugging#/runtime/this-firefox.
  3. Choose Load Temporary Add-on and select the extracted manifest.json. Permanent installation requires Mozilla signing.

FAQ

Good to know

Does SkipCam scan the whole desktop?

Screen scan captures the visible active browser tab. For codes elsewhere, upload or paste a screenshot.

Does a URL warning check the destination online?

Warnings come from offline heuristics. SkipCam does not check live phishing or malware reputation and never opens a decoded link automatically.

Can I scan multiple QR codes?

SkipCam can recover multiple distinct codes when they are spaced apart. If a code is missed, select it by itself.

Is SkipCam open source?

Yes. SkipCam is distributed under the MIT License. Read the license and browse the source on GitHub.
