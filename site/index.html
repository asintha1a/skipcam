Chrome, Edge and Brave

Get Chromium beta ZIP ↓
  1. Download and extract the Chromium ZIP from the release.
  2. Open your browser’s Extensions page and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder.

Firefox 140+

Get Firefox beta ZIP ↓
  1. Download and extract the Firefox ZIP from the release.
  2. Open about:debugging#/runtime/this-firefox.
  3. Choose Load Temporary Add-on and select the extracted manifest.json. Permanent installation requires Mozilla signing.

FAQ

Good to know

Does SnipRay scan the whole desktop?

Screen scan captures the visible active browser tab. For codes elsewhere, upload or paste a screenshot.

Does a URL warning check the destination online?

Warnings come from offline heuristics. SnipRay does not check live phishing or malware reputation and never opens a decoded link automatically.

Can I scan multiple QR codes?

SnipRay can recover multiple distinct codes when they are spaced apart. If a code is missed, select it by itself.

Where did SnipRay come from?

Self Graphic Lab independently maintains SnipRay, an enhanced MIT-licensed derivative of QR Snip by Isaac Joel Mithran.
