# Changelog

## 1.0.0-beta.2 — 2026-11-24

Rebranded the product as SkipCam and refreshed the extension, website and product assets. Existing scanning, generation, privacy and settings behavior is retained. This evaluation release updates extension display metadata and artwork; internal storage keys and the Firefox add-on ID remain stable for existing users. Automated tests and production builds pass; full browser QA remains pending.

## 1.0.0-beta.1 — 2026-11-24

First public evaluation prerelease under the previous product name. Includes the browser interface, local QR generation and image scanning, structured QR interpretation, offline URL inspection, optional private history, and separate Chromium and Firefox packages. Automated tests and builds passed; full browser QA remained pending.
